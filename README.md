# Hoa Le — Engineering & Development Portfolio

Portfolio tiếng Việt về MEP Engineering, Revit MEP & BIM, Automation và Full Stack Web. Dựng bằng React, TypeScript và Vite; giao diện responsive, sơ đồ MEP SVG, bộ lọc dự án và cửa sổ chi tiết.

## Chạy dự án

```sh
npm install
npm run dev
```

## Kiểm tra và build

```sh
npm run lint
npm run build
npm run preview
```

## Cá nhân hóa

- `src/App.tsx`: tên, phần giới thiệu, chuyên môn và danh sách `projects`.
- `src/App.css`: màu sắc và bố cục responsive.
- `index.html`: tiêu đề và mô tả SEO.
- `public/favicon.svg`: biểu tượng thương hiệu.

Tên Hoa Le là tên tạm. Các dự án và dữ liệu trong hình dashboard là concept minh họa, cần thay bằng hồ sơ thực tế trước khi công bố.

Biểu mẫu tạo file `project-brief.txt` tại máy người dùng; không gửi dữ liệu hay email. Để nhận liên hệ cần bổ sung địa chỉ thực tế hoặc tích hợp dịch vụ/backend gửi thư.

Font Be Vietnam Pro được tải từ Google Fonts, có font Arial dự phòng. Các hình minh họa được dựng bằng SVG và CSS, không cần ảnh từ bên ngoài.
